# Smart Food Expiry Detector

A Flask-based web application for tracking food inventory, monitoring expiry dates, and reducing food waste.

## Features

- Add food items
- Automatic expiry date calculation
- Fresh / Expiring / Expired classification
- Food waste analytics
- Dashboard with statistics
- Interactive charts
- SQLite database storage
- Delete food items

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Matplotlib

## Installation

```bash
git clone <repository-url>
cd smart-food-expiry-detector
pip install -r requirements.txt
